Core Features

FAQ

部署前，你可能想问

部署 Chatwoot 需要什么配置的服务器？

官方最低要求约 1 核 2G 内存、20G 磁盘即可跑起来，但实际建议 2 核 4G 内存 + 40G 以上 SSD。Chatwoot 由多个进程组成（Rails 应用、Sidekiq 后台任务、PostgreSQL、Redis），内存偏小时容易出现后台任务堆积。并发客服人数较多时，建议 4 核 8G 起。

系统是装在谁的服务器上？数据归谁？

装在你自己的服务器上，全部数据（对话记录、客户资料、附件）都存于你的磁盘与数据库中，我们不接触、不持有、不中转你的业务数据。你随时可以自己登录服务器查看、导出、迁移。

大概多久能上线？

服务器与域名就绪的前提下，标准部署一般 1 个工作日内完成并交付；需要接入 WhatsApp、配置邮件通道或对接内部系统的，视第三方审核时间而定，通常 1-3 个工作日。

后期升级、维护怎么办？

Chatwoot 迭代较快，建议跟随稳定版升级。我们提供两种情况：一是你自己按交付文档操作（我们会写好升级与回滚步骤）；二是把运维托管给我们，包含升级、备份巡检、故障排查与告警处理。

能不能对接微信 / 企业微信 / 钉钉？

Chatwoot 原生支持的是网站聊天、邮件、WhatsApp、Facebook、Instagram、Telegram、LINE、SMS 等渠道。微信生态需要通过开放 API 或第三方中转做定制对接，属于二次开发范围，我们可以评估后提供方案。

部署完我不会运维，会有人教我 / 帮我吗？

会。交付时我们会宣讲后台日常操作（客服分配、快捷回复、报表查看），并提供文档。标准方案含 30 天答疑；生产级与企业方案含更长周期的技术支持与运维托管选项。

会不会有版权或合规风险？

Chatwoot 本体以 MIT 协议开源发布，可免费商用、可修改、可自托管，这是它被广泛采用的基础。本站是独立的第三方部署服务，与 Chatwoot Inc. 无官方隶属关系；涉及的第三方渠道（WhatsApp 等）需遵守其各自平台政策。
